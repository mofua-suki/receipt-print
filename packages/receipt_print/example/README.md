# Receipt Print example

This example compiles a sample receipt and shows the command size, the ReceiptLine preview, and diagnostics.

If this directory came from the distribution archive, generate the Android and iOS app scaffolding with `flutter create --platforms=android,ios .`. If it came from a Git checkout, first build the required native files as described in the [package README](https://github.com/mofua-suki/receipt-print/blob/main/packages/receipt_print/README.md#run-the-example-or-build-from-source).

Run `flutter pub get` and `flutter run` here, then press the conversion button.
